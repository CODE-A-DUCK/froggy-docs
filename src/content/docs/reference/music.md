Froggy 支援從 YouTube / YouTube Music 播放音樂，並提供完整的播放控制與播放列表管理。

---

## 1. 加入與離開語音頻道

在使用音樂功能前，請先讓 Froggy 加入你所在的語音頻道。

1. 使用 `/join` 指令讓 Froggy 加入你目前的語音頻道
2. 完成後即可使用播放相關指令
3. 若要讓 Froggy 離開語音頻道，請使用 `/leave` 指令（播放中也可使用）

![join 和 leave 指令示意圖](/src/content/img/join1.jpg)
![leave 指令示意圖](/src/content/img/leave1.jpg)

> `/join` 與 `/leave` 指令使用範例

> 建議在開始播放前先使用 `/join`，避免後續操作出現錯誤。

---

## 2. 播放音樂的兩種方式

### 使用連結直接播放

直接使用 `/play` 指令 + YouTube 連結即可開始播放。

![play 指令示意圖](/src/content/img/play1.jpg)

> 使用 `/play <URL>` 播放指定音樂

### 搜尋後選擇播放

使用 `/search` 指令輸入關鍵字，Froggy 會在 YouTube 上搜尋並列出前 10 個結果供你選擇。

- 可單選或多選
- 多選時會依序加入播放列表

![search 搜尋介面](/src/content/img/search1.gif)

> `/search` 搜尋與選擇介面
---

## 3. 播放控制按鈕

播放音樂後會出現互動式控制面板，以下是各按鈕功能：

| 按鈕           | 功能說明                              |
|----------------|---------------------------------------|
| **暫停 / 繼續** | 暫停或恢復目前播放的歌曲              |
| **跳過**        | 跳過當前歌曲，播放下一首              |
| **循環**        | 切換循環模式（關閉 → 重播一次 → 單曲循環） |
| **詳情**        | 查看目前播放歌曲的詳細資訊            |

![播放控制按鈕示範](/src/content/img/buttons.gif)

> 播放介面控制按鈕

---

## 4. 停止播放與管理播放列表

### 停止播放
使用 `/stop` 指令可**停止目前播放並清空整個播放列表**。

### 查看與移除歌曲
使用 `/queue` 指令可查看目前播放列表，並直接點選歌曲從列表中移除。

![queue 播放列表介面](/src/content/img/queue1.jpg)

> 使用 `/queue` 查看與移除歌曲

> [!NOTE]
> 移除歌曲後，播放列表會自動更新，下一首會繼續播放。

---

## 總結

| 指令       | 功能                     | 常用情境             |
|------------|--------------------------|----------------------|
| `/join`    | 加入語音頻道             | 開始使用音樂功能     |
| `/leave`   | 離開語音頻道             | 結束使用             |
| `/play`    | 直接播放 YouTube 連結    | 已知連結時使用       |
| `/search`  | 搜尋並選擇音樂           | 想找歌時使用         |
| `/queue`   | 查看 / 移除播放列表      | 管理待播清單         |
| `/stop`    | 停止播放並清空列表       | 想完全停止時使用     |
