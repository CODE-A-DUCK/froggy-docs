---
title: 伺服器管理
description: 管理與版主指令
---

提供成員管理、身份組調整與頻道控制指令。

:::caution
需要 **管理員 (Administrator)** 或版主權限。
:::

---

## 1. 踢出與封鎖

| 指令        | 功能     | 必填            | 選填   |
| :---------- | :------- | :-------------- | :----- |
| `/kick`     | 踢出成員 | `@成員`         | `原因` |
| `/ban`      | 永久封鎖 | `@成員`         | `原因` |
| `/unban`    | 解除封鎖 | `@用戶`         | 無     |
| `/timedban` | 暫時封鎖 | `@成員`、`天數` | `原因` |

---

## 2. 身份組管理

| 指令          | 功能       | 必填               |
| :------------ | :--------- | :----------------- |
| `/addrole`    | 添加身份組 | `@成員`、`@身份組` |
| `/removerole` | 移除身份組 | `@成員`、`@身份組` |

---

## 3. 頻道管理

| 指令        | 功能     | 必填            | 選填   |
| :---------- | :------- | :-------------- | :----- |
| `/mute`     | 禁言成員 | `@成員`         | `原因` |
| `/unmute`   | 解除禁言 | `@成員`         | `原因` |
| `/slowmode` | 慢速模式 | `秒數`、`#頻道` | `原因` |

---

## 4. 暱稱管理

| 指令           | 功能          | 必填    | 選填           |
| :------------- | :------------ | :------ | :------------- |
| `/setnickname` | 設定/移除暱稱 | `@成員` | `暱稱`、`原因` |

:::note
若不填寫 `暱稱`，將重置為原本 Discord 名稱。
:::
